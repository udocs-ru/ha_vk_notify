### 🔑 Как получить Токен Пользователя (User Token) для отправки видео

Для получения токена необходимого для отправки нативных видео, мы используем — авторизацию через доверенное приложение (Kate Mobile), у которого уже есть все разрешения от ВК.

**Шаг 1: Переход по ссылке авторизации**
Скопируйте ссылку ниже и вставьте её в адресную строку браузера (вы должны быть авторизованы в ВК со своего основного аккаунта):

`https://oauth.vk.com/authorize?client_id=2685278&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=video,messages,offline&response_type=token&v=5.199`

*(Где `2685278` — это внутренний ID приложения Kate Mobile).*

**Шаг 2: Выдача прав**
Откроется страница с запросом доступа к вашим видеозаписям и сообщениям. Нажмите **«Разрешить»**.

**Шаг 3: Копирование токена**
1. Браузер перекинет вас на пустую белую страницу с надписью *"Пожалуйста, не копируйте данные из адресной строки..."*.
2. Кликните на **адресную строку браузера**.
3. Найдите ваш токен. Он начинается с `vk1.a.` и идет сразу после `access_token=`, вплоть до знака амперсанда (`&`).

**Пример адресной строки:**
`https://oauth.vk.com/blank.html#access_token=`**vk1.a.TvoJ_VeChNyJ_ToKeN_Tut...**`&expires_in=0&user_id=1234567`

Вот этот выделенный кусок — и есть ваш готовый `video_access_token`!

### 🚀 Использование токена в новом сервисе `vk_notify.send_video`

Полученный токен пользователя вставляется напрямую в параметры нового сервиса отправки нативных видеороликов. Ниже представлен пример конфигурации блока автоматизации в Home Assistant:

```yaml
alias: вк нативные видео
description: ""
triggers: []
conditions: []
actions:
  - action: vk_notify.send_video
    metadata: {}
    target:
      entity_id: notify.vk_notify_2000000003
    data:
      parse_mode: html
      disable_mentions: false
      inline_keyboard: true
      auto_answer_callback: true
      video_access_token: "ваш токен jahoijoii987cr8UHIUIUihiuh8ujiooijo869684t82gijkxnoiihoexihonohoihzvdvuxkb,mbkbibbkjbiu"
      file: /config/www/pre_clip_internal.mp4
mode: single
```

### ⚠️ Важные особенности работы службы send_video

* **Где сохраняются видео:** Загруженные ролики (например, записи с камер Frigate) физически сохраняются в разделе **«Мои видеозаписи»** того пользователя, чей персональный токен указан в автоматизации. Бот сообщества выступает лишь в роли "пересыльщика" этого вложения.
* **Время обработки:** Процесс конвертации ролика на серверах ВКонтакте под разные разрешения длится довольно долго (в зависимости от размера файла и загруженности серверов ВК это может занять от нескольких десятков секунд до нескольких минут).
* **Статус в мессенджере:** Сразу после отправки в чате ВК Мессенджера ролик появится со стандартной системной плашкой **«Идёт обработка видео»**. Это абсолютно нормальное поведение алгоритмов ВК. Спустя некоторое время надпись автоматически исчезнет, и видео станет доступно для просмотра в нативном плеере прямо внутри диалога.
